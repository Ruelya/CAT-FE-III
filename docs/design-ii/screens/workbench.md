# 主工作台（Workbench）

> 这是用户每天盯 8 小时的屏幕。本文的纪律：
> **网格单元格内部表达强度 1/10，其余区域可以到 8/10。**
> 所有"艺术"活在框、缝、矩阵、标识板；单元格里只有文字、标签、方灯。

| Masthead 标识板 | 无切角 | **右上 45° bevel**（全屏唯一切角） | 品牌板标识，与 Index Spine 呼应 |

## 2. Filter Rail（44px）

只留 F1 频率档：**状态筛选 · 匹配筛选 · 问题导航**。

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ▎全部 1,248 │ 未翻译 73 │ 草稿 401 │ 已确认 774 │ 问题 3 ┊ 匹配 全部 ▾ ┊ ‹ 问题 1/3 › │
└──────────────────────────────────────────────────────────────────────────┘
   Active Axis 驻留于当前 chip 下缘
```

| 组 | 控件 | 规格 |
| --- | --- | --- |
| **状态 chip 组** | 5 个 chip：全部 / 未翻译 / 草稿 / 已确认 / 问题 | 高 28px，圆角 4px，`--frame` 底；每个 chip = `方灯 + 文字 + Mono 计数`；当前项 `--shade` 底 + 下缘 Active Axis。`Alt+1..5` 切换 |
| **匹配筛选** | 下拉：全部 / 101% / 100% / 95–99% / 85–94% / 75–84% / 50–74% / 无匹配 / 仅 MT | 32px 高选择器，`--deck` 底 |
| **问题导航** | `‹ 问题 n/N ›` | Mono 计数；`F8` 下一个、`Shift+F8` 上一个；N=0 时整组禁用并显示 `无问题` |

**移出去的东西**（→ 命令面板 / 快捷键 / 行内）：

| 原控件 | 去向 |
| --- | --- |
| 文内搜索框 | `Ctrl+F` 打开**查找替换抽屉**（§7） |
| Exact TM 开关 | Stack 面板头的匹配设置 popover |
| `⌘` 快捷键面板 | 命令面板 `?` 前缀 / 设置 |
| 放大镜（Concordance） | `Ctrl+Shift+F`，结果进 Stack 的匹配区 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`，无按钮（有全局历史在洞察页） |
| 批注 | `Ctrl+M`，行内批注标记 + 批注抽屉 |
| Confirm 按钮 | 行内确认区 + `Ctrl+Enter` |

**结果**：控件数 8 组 → 3 组，标签不再被裁切（对照实拍里 `Issue` 被搜索框压住）。

## 3. 段落网格

### 3.1 列结构

| 列 | 宽 | 内容 | 对齐 |
| --- | --- | --- | --- |
| ID | 56 | 段号（Mono 13，`tabular-nums`）。无装饰标点 | 右 |
| 状态 | 40 | 8px 方灯（形状编码）+ 可访问文本 | 居中 |
| 原文 | `minmax(320px, 1fr)` | 源文 + 受保护标签 | 左 |
| 译文 | `minmax(320px, 1fr)` | 可编辑；`--deck` 底 | 左 |
| 来源 | 44（可选，≥1600px 才显示） | 匹配来源微标：`101 / 100 / 96 / MT / —` | 右 |

**列宽可拖**：原文/译文之间的分隔缝可拖（40/60 ↔ 60/40），双击回 50/50。持久化。

### 3.2 行的解剖

```
┌────┬──┬───────────────────────────────────┬──────────────────────────────┬───┐
│▎418│ ◧│ The Supplier shall maintain ⟦1⟧   │ 供应商应采取商业上合理的管理、  │96 │
│    │  │ commercially reasonable           │ 技术和物理安全措施。⟦1⟧        │   │
│    │  │ administrative safeguards.⟦/1⟧    │                              │   │
│    │  ├───────────────────────────────────┴──────────────────────────────┤   │
│    │  │ ⚠ 数字不一致：原文含 "30"，译文含 "60"。         定位  忽略(需理由) │   │
└────┴──┴──────────────────────────────────────────────────────────────────┴───┘
 ▎= Active Axis   ◧ = 状态方灯   ⟦1⟧ = 受保护标签胶囊
```

| 元素 | 规格 |
| --- | --- |
| 行高 | `min-height: var(--row-min)`（Standard 48px），实际由内容撑开 |
| 行分隔 | 底缘 1px `--rule`。**不是卡片**，无圆角、无投影、无 margin |
| 行底色 | 默认 `--paper`；hover `--shade`；活动行 `--shade` + 左缘 Active Axis |
| 原文单元格 | `--deck` 底（可选中、可复制、F2 可进入原文更正模式） |
| 译文单元格 | `--deck` 底 + 1px `--rule-field` 边框；聚焦时边框变 `--signal` 2px |
| 内联 QA | 行底部附一条 `--frame` 带，左缘 3px 状态色；含图标 + 规则文案 + 两个动作 |
| 单元格内装饰 | **零**。无纹理、无线条、无水印、无角标 |

### 3.3 状态方灯（形状 + 色 + 文本三重编码）

| 状态 | 形状 | 色 | 可访问名 |
| --- | --- | --- | --- |
| 未翻译 | 8px 空心方（1.25px 描边） | `--rule-field` | `未翻译` |
| 草稿 | 8px 下半填方 | `--text-2` | `草稿` |
| 已确认 | 8px 实心方 | `--ok` | `已确认` |
| 已审校 | 8px 实心方 + 右上 3px 缺角 | `--ok` | `已审校` |
| 已签发 | 8px 实心方 + 外框 | `--ok` | `已签发` |
| 有错误 | 8px 实心方 + 白色叉 | `--err` | `有 QA 错误` |
| 有警告 | 8px 实心方 + 白色斜杠 | `--warn` | `有 QA 警告` |
| 已锁定 | 8px 实心方 + 中央横条 | `--text-2` | `已锁定` |

**色盲验证**：仅凭形状（空 / 半 / 实 / 缺角 / 外框 / 叉 / 斜杠 / 横条）即可区分全部 8 态。

### 3.4 受保护标签（Tag）

**它们是功能控件，不是装饰括号。**

| 项 | 规格 |
| --- | --- |
| 外观 | 内联胶囊：`--frame` 底、1px `--rule` 边、2px 圆角、Mono 11px、内距 3px 5px |
| 编号 | `1`、`2`… 成对标签共用编号，闭合标签加下划线（`1` vs `1̲`） |
| 配对高亮 | hover/聚焦任一半 → 两半同时 `--signal-wash` 底 + `--signal` 边 |
| 缺失 | 译文缺某标签 → 该标签在原文侧显示 `--err` 虚线边；行内 QA 报错 |
| 错序 | 译文标签顺序 ≠ 原文 → `--warn` 边 + 内联提示 |
| 插入 | `F9` 插入下一个待插标签；`Ctrl+Shift+T` 复制原文全部标签结构；`Alt+←/→` 移动光标处标签 |
| 键盘导航 | 译文单元格内 `Ctrl+←/→` 在标签之间跳；标签是原子单位（退格整体删除并提示可撤销） |
| 不可做 | ❌ 标签内不显示原始 XML；❌ 不用 `<>` 尖括号字面量；❌ 不可拖拽（拖拽在密集文本里误操作率高，改用 `Alt+←/→`） |

### 3.5 行内动作（悬停/聚焦才出现）

上一代把 5 个图标常驻在活动行右侧（实拍可见），与译文竞争。现在：

- **默认不显示**。行 hover 或行内任一元素获得焦点时，在**原文/译文列的分隔缝上**浮出一个
  24px 宽的竖向动作条（`--frame` 底、1px 缝），含 3 个按钮：
  `插入 TM 最佳匹配` / `批注` / `更多 ⋯`。
- `更多` popover：复制原文到译文、清空译文、拆分段落、合并下一段、锁定、
  原文更正、简繁转换、添加术语、Concordance。
- **全部有快捷键**，行内按钮只是可发现性入口。

### 3.6 选择与批量

| 操作 | 行为 |
| --- | --- |
| 单击行（非译文区） | 选中该行，Axis 迁移，译文**不**自动聚焦 |
| 单击译文区 | 选中 + 聚焦译文，光标落在点击位置 |
| `Shift+↑/↓` | 扩展选择；Axis 停在锚点行，其余选中行 `--shade` + 左缘 1px `--rule-strong` |
| `Ctrl+Shift+A` | 全选（当前筛选范围内） |
| 多选后动作条 | 网格顶部滑入一条 36px 的**批量条**（`--ink` 面）：`已选 24 段` + 确认 / 清空译文 / 锁定 / 预翻译 / 加批注 / 取消选择。**破坏性动作必须二次确认** |
| 退出 | `Esc` 清除多选并把 Axis 留在锚点行 |

### 3.7 虚拟化与性能

```tsx
// 窗口化 + content-visibility 双保险
<div className="grid" style={{ "--row-h": ROW_H } as CSSProperties}>
  <div style={{ height: offsetTop }} />
  {window.map(row => <SegmentRow key={row.id} {...row} />)}
  <div style={{ height: offsetBottom }} />
</div>
```

```css
.grid { scrollbar-width: none; overflow-y: auto; overscroll-behavior: contain; }
.grid::-webkit-scrollbar { display: none; }   /* 滚动条由 Document Matrix 承担 */
.seg-row {
  content-visibility: auto;
  contain-intrinsic-size: auto var(--row-min);
  contain: layout style;
}
```

- 窗口 100 行，overscan 18（沿用现值）。
- 行高不定（CJK 换行）→ 用 `ResizeObserver` 维护测量缓存，Matrix 的视口括号据此计算。
- 目标：1 万段滚动 P95 帧时间 ≤ 33ms。

### 3.8 空态与加载

| 情况 | 呈现 |
| --- | --- |
| 加载中 | **骨架屏**：与最终行结构同形的灰条（`--frame`），8 行，无动画（或极缓 shimmer 且 Reduced Motion 下关闭）。**禁止圆形 spinner** |
| 筛选无结果 | 网格区居中偏左：`--t-title` 一句 `当前筛选没有匹配的段落` + `--t-body` 一句说明当前筛选条件 + 一个 `清除筛选` 次级按钮。右侧大留白铺 Inert Matrix |
| 文档为空 | `这个文件没有可翻译内容` + 说明（如"全部内容被样式排除规则过滤"）+ `查看内容筛选设置` |
| 引擎断开 | 网格上方插入 `--err` 前缘的横幅：`引擎连接中断，正在重连…` + `重试`。**已输入的草稿保留在本地日志**，横幅注明这一点 |

## 4. STACK 面板（原 Suggestions）

### 4.1 为什么推翻标签制

实拍 `15-suggestions-terms.png`：`Matches | Terms | Assistant | QA` 四标签互斥。
但译员的真实工作是**同时**看 TM 匹配和术语命中——Trados 与 memoQ 都把
Translation Results 与 Term Recognition 做成**两个同时可见的窗格**。
互斥标签让用户每段都要切两次。

### 4.2 新结构：常驻双区 + 抽屉

```
┌────────────────────────────────────────┐
│ ▛▀▀▀▀▀▀▀▀▀▀▀▀▜  ∴∴∴∴∴∴∴∴∴∴∴∴∴∴∴∴  ⟨› │ ← 品牌板（bevel 右上）+ Inert Matrix + 折叠
│ ▌ 建议        ▌                        │
│ ▙▄▄▄▄▄▄▄▄▄▄▄▄▟                        │
├────────────────────────────────────────┤
│ 匹配 3        排序 ▾  设置 ▾           │ ← 区头（sticky）
│ ┌────────────────────────────────────┐ │
│ │ 96%  Legal EN–ZH        2025-05-14 │ │
│ │ 原文  The Supplier shall maintain  │ │
│ │       ▁▁▁▁▁▁▁▁▁ commercially       │ │ ← 词级 diff：删除线/下划线，不用色块
│ │ 译文  供应商应采取商业上合理的…      │ │
│ │ 来自 Master Services Agreement v3  │ │
│ │                        插入  ⌘1    │ │
│ └────────────────────────────────────┘ │
│ … 更多匹配                              │
├────────────────────────────────────────┤ ← 结构缝
│ 术语 2                          添加 + │ ← 区头（sticky）
│ Supplier → 供应商        首选          │
│ safeguards → 安全措施    首选          │
├────────────────────────────────────────┤
│ ▸ AI 助手                     未启用   │ ← 抽屉（默认收起，32px）
└────────────────────────────────────────┘
```

| 区 | 默认状态 | 规则 |
| --- | --- | --- |
| **匹配 Matches** | 常驻，占剩余高度的主体 | 至少显示 2 条完整卡；滚动 |
| **术语 Terms** | 常驻，`max-height: 30%` | 命中通常 0–5 条；超出内部滚动 |
| **AI 助手** | 抽屉，收起 32px | 展开时占 50%，匹配区相应压缩但不低于 180px |
| **QA** | **不在 Stack 里** | QA 问题显示在**行内**（§3.2）+ QA 复核 Surface。Stack 里再放一份是重复 |

**高度分配可拖**：匹配/术语之间的缝可拖；比例持久化。

### 4.3 匹配卡（Match Card）

| 元素 | 规格 |
| --- | --- |
| 匹配率 | 左上，Mono 13px，带底色块：101%/100% = `--ok` 淡染；95–99% = `--frame`；<95% = 无底 |
| 库名 | `--t-meta`，`--text-2` |
| 日期 | 右上，Mono 12.5px，`--text-2` |
| 原文/译文 | `--deck` 底，`--t-editor` 字号（与网格同字号，便于比对） |
| **词级 diff** | 删除词：`--text-2` + 删除线；新增词：`--text-1` + 1px 下划线。**不用彩色背景块**——上一代用绿/蓝色块，与状态色语义冲突 |
| 来源 | `--t-meta`，`来自 <文档名>`（可点击 → Concordance 上下文） |
| 插入 | 右下，次级按钮 + `⌘1..9` 提示。`Alt+1..9` 直接插入第 n 条 |
| 卡几何 | **不是卡片**：区块之间用 1px `--rule-soft` 分隔，无圆角无边框。仅当前项 `--shade` 底 + 左缘 Axis |

### 4.4 术语条（Term Row）

单行紧凑：`原文词 → 首选译法` + 状态标记（`首选` / `禁用` / `待定`）。
`禁用` 用 `--err-ink` 文字 + 叉形标记。hover 展开 popover 显示定义、词性、例句、来源术语库。
`Ctrl+Q` 从当前选区添加术语（打开术语添加对话框，预填原/译文）。

### 4.5 AI 助手抽屉

| 项 | 规格 |
| --- | --- |
| 收起态 | 32px 条：`▸ AI 助手` + 当前引擎名（或 `未配置`）+ 一个 `⌘↵ 生成` 提示 |
| 展开 | 引擎/模型选择器（`--deck`）、**接地内容摘要**（可展开查看真正注入的术语/TM/风格/文档上下文）、生成结果、动作 |
| 接地摘要 | 必须**可点开看到实际注入内容**。不允许只写 "grounded" 之类的声称（PRD F-03 要求"注入内容可见可配"） |
| 结果动作 | `替换` / `插入` / `对比 diff` / `重新生成` / `停止` |
| 机器来源标注 | 结果块左缘 3px `--machine` + 一行 `--t-micro`：`来自 <provider> · <model>`。**永不省略** |
| 流式 | 见 `04-motion.md` 编排 F |
| 全局关闭 | 若设置里 AI 总开关关闭 → 抽屉显示 `AI 辅助已关闭` + `前往设置` |
| 离线 | 无可用引擎时显示 `OfflineAssistantPanel` 的等价内容：说明本地可用的动作（TM/术语/QA）与如何配置引擎 |

### 4.6 面板头与折叠

- 标题块：`--ink` 底，标题 `建议` 用 Jost 20/500。
- 标题右侧余幅：Inert Matrix，裁切到板块边界。
- **折叠控件：整屏唯一一个**，位于标题块最右，32×32 方形（4px 圆角），
  展开态显示 `›`（右向），收起后面板变成贴窗口右缘的 **40px 轨道**，轨道内一个 `‹`（左向）。
  **绝不同时显示双向箭头；绝不使用悬浮胶囊**（这是上一代母版的明确缺陷）。
- 快捷键 `Ctrl+9`。折叠动效见 `04-motion.md` 编排 C。

### 5.3 预览内容

| 格式 | 呈现 |
| --- | --- |
| DOCX / HTML / MD | **真实页面结构**：页面白纸（`--deck`）、页边距、段落排版、表格、列表。左侧 84px 页面缩略图纵列（当前页高亮），右侧渲染页 |
| PDF（文本层） | 渲染页 + 版面框；显示"尽力保真"标注 |
| PDF（扫描件/OCR） | **原图 vs OCR 文本双栏对照**（PRD B 专述要求），错误 OCR 可就地更正 |
| XLSX | 表格网格片段，高亮当前单元格 |
| PPTX | 幻灯片缩略 + 当前形状高亮 |
| 不支持/降级 | 明确说明限制与原因（如"该格式仅提供引擎结构顺序，无页面版式"），**绝不显示假页面**。当前实现的 `Engine structure path` 属于此类，需配文案说明 |

### 5.4 联动

- 当前段在渲染页中用**一条 `--signal-wash` 淡染 + 左缘 2px `--signal`** 定位（不是橙色描边框）。
- 点击预览内容 → 跳到对应段并把 Axis 迁过去；**保留译文单元格焦点**。
- `跟随当前段` 勾选时，切段自动翻页（跳页用 `04-motion.md` 编排 G 的远距离规则）。
- 预览页面本身**不承载任何装饰覆盖层**——它是"真实文档"的表征。
- 弹出独立窗口（`⧉`）：把预览开到第二显示器；主窗口把坞收起并显示 `已在独立窗口中打开`。

## 6. 译文单元格（编辑核心）

### 6.1 几何

```css
.cell-target {
  background: var(--deck);
  border: 1px solid var(--rule-field);
  border-radius: var(--r-input);
  padding: var(--cell-pad) var(--s-5);
  font: 400 var(--t-editor)/var(--lh-editor) var(--font-ui);
  field-sizing: content;          /* 随内容增高，Chromium 123+ */
  min-block-size: calc(var(--row-min) - var(--cell-pad) * 2);
  /* IME 候选窗需要的呼吸空间 */
  scroll-margin-block: 96px;
}
.cell-target:focus-visible {
  border-color: var(--signal);
  border-width: 2px;
  outline: none;                  /* Axis 与边框合一，不再叠一层 outline */
  padding: calc(var(--cell-pad) - 1px) calc(var(--s-5) - 1px);
}
```

### 6.2 行为

| 项 | 规格 |
| --- | --- |
| 自动增高 | `field-sizing: content`。**IME 组合态期间禁止增高动画**（`transition: none` when `[data-composing]`） |
| 自动补全 | 术语 / TM 片段 / MT 尾部预测。以**内联灰字幽灵文本**呈现（`--text-2`），`Tab` 接受，`Esc` 拒绝。可关。**组合态期间不弹** |
| 拼写/错别字 | 波浪下划线（`text-decoration: underline wavy`），颜色 `--warn`。右键给建议 |
| 非打印字符 | 可选显示：空格 `·`、制表 `→`、换行 `¶`，用 `--text-3` |
| 撤销 | 单元格内 `Ctrl+Z` 走浏览器原生栈；跨段撤销走应用栈（`Ctrl+Alt+Z`）——两者分离，避免"撤销把上一段也撤了" |
| 保存 | 停止输入 400ms 后写草稿日志；`Ctrl+Enter` 确认时写库。崩溃恢复见 `screens/system.md §3` |

## 7. 查找替换抽屉（`Ctrl+F`）

**不用弹窗**——弹窗会遮住结果。改为**从筛选栏下方推出的 52px 抽屉**（`--frame` 面，1px 结构缝）。

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 查找 [safeguards        ] 替换 [安全措施      ]  Aa  ab|  .*  范围: 本文件▾ │
│ 12 处匹配 · 第 3 处            上一处 ↑  下一处 ↓   替换  全部替换  关闭 ✕ │
└──────────────────────────────────────────────────────────────────────────┘
```

- 命中在网格中用 `--signal-wash` 底 + 1px `--signal` 下划线标出；当前命中额外加 2px 左缘。
- 范围：本文件 / 本项目 / 仅原文 / 仅译文 / 仅已确认。
- 正则模式（`.*`）打开时，输入框字体切 Mono，语法错误内联提示。
- `全部替换` **必须**先显示预览表（前 20 条 before→after）+ 影响段数，确认后执行，并可整体撤销。
- `Enter` = 下一处；`Ctrl+Enter` = 替换并下一处；`Esc` = 关闭并把焦点还给原单元格。

## 8. 其他工作台叠层

| 叠层 | 触发 | 形式 | 要点 |
| --- | --- | --- | --- |
| **批注** | `Ctrl+M` / 行内按钮 | 右侧 360px 抽屉（Stack 之上，带遮罩仅覆盖 Stack） | 段级线程；作者、时间、编辑/删除、解决；导出可含。段有批注时 ID 列右上角一个 4px 方点 |
| **审校修订** | Surface 内命令 `审校模式` | 网格进入 diff 呈现：译文单元格显示修订痕迹（删除线 + 下划线），行内 `接受` / `拒绝` | 不是弹窗；是网格的一种渲染模式。顶部插入 36px 模式条说明当前处于审校模式 + 退出 |
| **拆分/合并** | `Ctrl+Shift+S` / `Ctrl+J` | 就地：拆分时在光标处插入一条 2px `--signal` 分割预览线 + 确认；合并时下一段行以 `--shade` 预高亮 | 无弹窗。可撤销 |
| **原文更正** | `F2` | 原文单元格变为可编辑（`--deck` + `--signal` 边框），底部出现 40px 条：`更正原因` 输入 + 保存/取消 | 留痕（PRD C-16）。更正后原文旁出现 8px "已更正"标记，hover 显示原值与原因 |
| **简繁转换** | 命令面板 | 抽屉：转换方向、配置档、词汇级选项、**预览受影响段数** + 应用/取消 | 必须先预览再应用；可整体撤销 |
| **编辑器偏好** | `Ctrl+,` | **不是模态**，是 Surface 内右侧 420px 抽屉 | 主题、缩放、密度、非打印字符、自动补全、CJK 空格、标点辅助、快捷键预设（Default/Trados/memoQ）与自定义表 |
| **Concordance** | `Ctrl+Shift+F` | 结果注入 Stack 的匹配区顶部，加一条 `Concordance: "xxx"` 区头 + 清除 | 不新开窗口 |
| **插件面板** | 插件声明 `placement: right/bottom` | 作为 Stack 的**新增区**或坞的**新增标签**接入 | 插件面板必须带 `插件：<名称>` 归属条与权限说明入口（`screens/ai.md §4`） |

## 10. 工作台验收清单

- [ ] 活动原文/译文对是全屏最强焦点
- [ ] 网格宽度 ≥ 视口的 60%（Stack 展开时）
- [ ] 单元格内零装饰；Inert Matrix 不出现在任何可读文本之后

- [ ] Active Axis 全屏恰好 1 条

- [ ] 折叠控件单向、单个、非悬浮
- [ ] 最小字号 ≥ 11px；可编辑文本 ≥ 14px
- [ ] IME 组合态下：不确认、不移焦、不切面板、不做单元格高度动画、不弹自动补全
- [ ] 1 万段 + Stack 展开 + 预览展开 + 125% 缩放下仍可操作，P95 帧时间 ≤ 33ms
