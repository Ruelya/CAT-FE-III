# AI 与插件：控制台 · 助手 · AI 动作 · 插件系统

> PRD 原则 2（使用者主权）：**AI 产出标注来源、可整体关闭；工具服务判断，不做不可见决定。**
> 本文的每一条界面规定都是这句话的兑现。

---

## 1. AI 控制台（Surface `ai`）

三个横向 Tab：**引擎与配置档** / **批处理** / **用量**。

### 1.1 引擎与配置档

```
┌──────────────────────────────────────────────────────────────────────────┐
│ AI 控制台                                     AI 辅助  ●已启用   [全部关闭] │
├────────────────────┬─────────────────────────────────────────────────────┤
│ 配置档              │  接地翻译（默认）                        [测试连接]   │
│                    │  ─────────────────────────────────────────────────  │
│ ▎接地翻译  默认     │  连接器   OpenAI 兼容端点          内置 · schema v2  │
│   OpenAI 兼容       │  Base URL https://…                                 │
│                    │  模型     <由用户填写>                               │
│  离线助手           │  凭据     ●已存入系统凭据管理器      [更换] [删除]    │
│   无外部调用        │  ─────────────────────────────────────────────────  │
│                    │  接地内容                                            │
│  术语抽取           │  ☑ 术语与禁译词      ☑ Top-5 相似 TM 例句            │
│   <provider>        │  ☑ 风格指令          ☐ 文档级上下文（前后各 2 段）   │
│                    │  [查看一次真实注入内容 →]                             │
│ [新建配置档]        │  ─────────────────────────────────────────────────  │
│                    │  执行     并发 4 · 每分钟 60 次 · 超时 30s · 月预算   │
│                    │  允许来源 <显式白名单>                                │
└────────────────────┴─────────────────────────────────────────────────────┘
```

| 项 | 规格 |
| --- | --- |
| **全局开关** | 页头右上 `AI 辅助 ●已启用 / [全部关闭]`（PRD G-12）。关闭后：Stack 的 AI 抽屉、划词 AI 菜单、养护的引擎模式、预翻译全部禁用并显示统一说明 |
| 连接器来源 | 每个配置档标注 `内置` / `插件` + schema 版本（`ai.connectorBuiltin` / `connectorPlugin` / `connectorSchemaVersion`）。插件连接器额外带 §G5 Provenance Strip |
| 连接器状态 | `可用 / 降级 / 不可用`（`ai.connectorAvailable/Degraded/Unavailable`），降级要说明降级原因 |
| 凭据 | **只显示"已存入系统凭据管理器"，永不回显明文**（PRD M-02）。动作只有 `更换` / `删除` |
| **接地内容** | 四个复选 + **`查看一次真实注入内容 →`**。点开是 §G6 Grounding Inspector：显示上一次真实请求注入的术语列表、TM 例句原文、风格指令全文、文档上下文。**没有这个检查器就不许在界面里写"接地"**（PRD F-03） |
| 测试连接 | 结果就地显示：成功（延迟 ms + 返回的模型标识）/ 失败（HTTP 状态 + 可读原因 + 常见修复建议）。`ai.testTimeout` 时说明超时值 |
| 允许来源 | 引擎白名单（PRD M-03），项目级可覆盖。**不做成合规卖点**，就是一个朴素列表 |
| 不允许 | ❌ 虚构模型版本号；❌ "推荐"徽章；❌ 质量评级；❌ 未经证实的能力声明（PRD 内容规则） |

### 1.2 批处理

- **发起**：范围（全项目 / 当前文件 / 当前筛选 / 已选段落）+ 配置档 +
  `TM 优先`（阈值可调，`ai.tmFirst` / `ai.tmThreshold`）+ `是否覆盖已有草稿`（`ai.replaceDrafts`，默认否）。
- **预估**：发起前显示 `将处理 n 段 · 预计 m 次调用 · 约 x 分钟`。预估基于真实并发/限速，不编造。
- **运行中**：
  - Live Matrix（每点 = 一个任务单元：待处理 / 处理中 / 成功 / 失败），
  - 确定性进度条 + 计数 + 已用 token，
  - `暂停` / `取消` / `在后台继续`。
- **可恢复**：断点续跑（`ai.resume`）、失败重试（PRD F-04）。队列持久化（`ai.durableQueue`），
  重启后仍在，界面要显示 `n 个任务在队列中等待`。
- **完成**：结果摘要 + 失败清单（可导出）+ `查看被修改的段落`（跳工作台并筛选）。

### 1.3 用量

- 按 `项目 / 引擎 / 月` 统计（PRD G-12）：输入 token、输出 token、缓存读写、思考 token、调用次数。
- 一条 §D3 堆叠比例条按引擎分解。
- 月预算：设定值 + 已用比例；超过 80% 时 §A8 `--warn` 横幅；超预算时**阻断新批处理**并说明。
- **明确标注**：`本地统计，不上报`（PRD M-04 遥测默认关闭）。

## 2. 编辑器内的 AI

### 2.1 Stack 助手抽屉

见 `screens/workbench.md §4.5`。补充：

| 项 | 规格 |
| --- | --- |
| 会话 | 段级会话（`assistant.conversation`）。切段时会话保留但折叠；`新建会话` 显式清空 |
| 提问 | 输入框 + `发送`（`Ctrl+Enter`）。占位符是 `问关于这一段的问题`，**不是营销文案** |
| 思考态 | `assistant.thinking`：2px 往复轨 + `正在生成…` + 已用时间（Mono）。**可停止** |
| 结果 | §G5 来源条（provider/model/推理档）+ 正文 + 动作（`用于译文` / `插入` / `对比` / `丢弃`） |
| 对比 | §D8 词级 diff：当前译文 vs 建议译文 |
| 指标 | 折叠的 `assistant.metrics`：输入/输出/缓存/思考 token、耗时。默认收起 |
| 无引擎 | `离线预览`（`assistant.offlinePreview`）：说明本地可做什么（TM、术语、QA），并给配置入口 |
| 无活动段 | `assistant.noActiveSegment`：`选择一个段落后可以提问` |
| 失败 | §F5：失败原因 + 是否消耗了配额 + `重试` / `换配置档` |

### 2.2 划词 AI 动作（PRD G-01）

在原文或译文中选中文本 → 出现锚定的 §A4 Popover（**不是浮动工具条**，锚定选区末端）：

```
┌────────────────────────┐
│ 润色                    │
│ 更正式                  │
│ 更口语                  │
│ 缩短                    │
│ 扩展                    │
│ 直译 ↔ 意译             │
│ ──────────────────────  │
│ 解释这句原文             │
│ ──────────────────────  │
│ 插件动作 (2)         ▸  │
└────────────────────────┘
```

- 执行后结果以 **§D8 词级 diff** 呈现在译文单元格下方的临时条（不是弹窗），
  动作：`采纳` / `丢弃` / `重试`。
- 插件贡献的动作在独立分组，带插件名与权限提示（`PluginAiActions`）。
- **IME 组合态期间不弹出此菜单。**

### 2.3 一致性修复助手（PRD G-04）

改某术语译法后，若该术语在文档中还有 n 处 → 出 §A7 Toast：
`"actuator" 在另外 14 段中使用了不同译法 · 查看`。
点击进入抽屉：清单 + 每条的 before/after + 全选/单选 + `批量应用`（需预览与撤销）。

## 3. 插件系统（PRD P 模块）

### 3.1 插件页（洞察 → 插件）版面

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 插件                                        [安装插件包…]  [随包插件 3 →] │
├──────────────────────────────────────────────────────────────────────────┤
│ ▎IDML 过滤器            v1.2.0   Tier 3 · 进程外    ●已启用   [⋯]        │
│   格式过滤器 ×1 · 管线步骤 ×1                                             │
│   权限：读取项目文件 ✓已授权 · 网络 ✗未请求 · 子进程 ⚠OS 层无法强制         │
│   兼容：引擎 schema v2 ✓ · 上次崩溃 0 次                                   │
├──────────────────────────────────────────────────────────────────────────┤
│ ▎术语一致性检查          v0.9.1   Tier 1 · 声明式    ○已停用   [⋯]        │
│   QA 规则 ×4                                                              │
│   权限：读取术语库 ✓已授权                                                 │
├──────────────────────────────────────────────────────────────────────────┤
│ ▎某引擎连接器            v2.0.0   Tier 2 · 沙箱 JS   ⚠不兼容  [⋯]        │
│   引擎连接器 ×1 · UI 面板 ×1                                              │
│   需要连接器 schema v3，当前为 v2 · 已阻止加载                             │
└──────────────────────────────────────────────────────────────────────────┘
```

### 3.2 每个插件条目必须显示

| 字段 | 说明 |
| --- | --- |
| 名称 · 版本 · Tier | Tier 1 声明式 / Tier 2 沙箱 JS / Tier 3 进程外（design-notes §3） |
| 贡献点清单 | `格式过滤器 ×1 · QA 规则 ×4 · UI 面板 ×1 · AI 动作 ×2 · 管线步骤 ×1` |
| **权限表**（§G7） | 每项能力 + 状态：`✓已授权` / `✗未请求` / `⛔已拒绝` / `⚠未知` |
| **诚实声明** | Tier 3 的进程/文件系统权限标 `⚠ OS 层无法强制`，并链接说明。**这是产品诚信要求，不得省略**（design-notes §3） |
| 兼容性 | schema 版本、descriptor 版本、config 版本；不兼容时**阻止加载**并说明缺什么 |
| 稳定性 | 崩溃计数（`plugins.crashCount`）；崩溃过的插件带 `--warn` 标记 |
| 来源 | `随包` / `本地安装（路径）`，安装包哈希可展开查看 |

### 3.3 安装流程

`安装插件包…` → 选择文件 → **检视对话框**（`plugins.inspect*`）：
ID、版本、Tier、许可证、来源哈希、贡献点、**请求的权限清单**、兼容性判定。
→ 用户逐项授权（默认最小权限）→ 确认安装。
- ID 不匹配（`plugins.inspectIdMismatch`）→ 阻断。
- 升级已装插件时显示**版本差异**与权限变化（新增权限必须重新授权）。

### 3.4 版本历史与回滚

每个插件的 `⋯` → `版本历史`：版本、激活修订、变更、状态。支持 `回滚到上一版本`。
禁用 / 卸载在同一菜单，卸载为 `danger` 并说明"其贡献的规则/过滤器将失效，已产生的数据保留"。

### 3.5 插件产出的可追溯性

| 场景 | 呈现 |
| --- | --- |
| 插件 QA 规则的发现 | 问题条目带 §G5：`来自插件 <名称> v1.2` + 规则契约版本 |
| 插件管线步骤的运行 | 洞察 → 分析里的管线历史：步骤名、插件、耗时、输入/输出计数、是否可取消/可恢复 |
| 插件 AI 动作的产出 | 结果条带插件名 + `未审` 标记（`--warn`），采纳后才转为普通译文 |
| 插件 UI 面板 | 见 §3.6 |

### 3.6 插件 UI 面板宿主（PluginPanelHost）

插件面板作为 **Stack 的新增区** 或 **预览坞的新增标签** 接入，**不允许**全屏或浮动。

- 面板顶部**强制**一条 24px 归属条（`--frame` 底）：
  `插件：<名称>` + 权限图标 + `⋯`（查看权限 / 停用 / 报告问题）。**插件不能移除这条。**
- 面板内容在 iframe/isolate 中渲染，**继承宿主的 token**（通过注入的 CSS 自定义属性），
  但**不能**改写宿主 token，不能使用 `--signal` 作为大面积填充，不能绘制 Band 或 Live Matrix
  （避免伪装成产品原生数据）。
- 面板不可弹出模态到宿主之上；需要确认时通过宿主提供的 API 调用宿主的 §A5 Dialog。
- 崩溃时：面板区域替换为 §F5 Error State：`该插件面板已停止响应` + `重载` / `停用插件`，
  **主程序不受影响**（NFR 可扩展性：插件崩溃不拖垮主程序）。

## 4. AI 相关的全局禁令

- ❌ 任何 AI 产出不带来源标注
- ❌ 用 "grounded / 接地" 字样而没有 §G6 可检查
- ❌ 伪造 token 用量、伪造延迟、伪造模型名
- ❌ 把 AI 建议直接写入译文而不经用户采纳（预翻译除外，且预翻译写入的是**草稿**状态并带来源）
- ❌ AI 全局关闭后仍有任何外部调用（包括"仅统计"）
- ❌ 用循环动画暗示"AI 正在思考"而实际没有请求在飞
- ❌ 营销词（Elevate / Unleash / Seamless / Next-gen / Intelligent workflow）
