## 1. 设置（Surface 级页面，不是模态）

### 1.1 推翻了什么

实拍 `08-settings-dialog.png` / 现实现 `ProductSettingsPage.tsx`：设置是一个覆盖全屏的**模态**，
由右下角一个**浮动齿轮 FAB**（`shell-settings-fab`）唤起。
两个问题：① 浮动 FAB 违反"没有浮层"命题；② 设置内容有 7+ 个分组，模态承载不了，且不能深链。

### 1.2 新结构：Surface + 竖向 Tab List（§E3）

入口：Index Spine 工具区的齿轮，或 `Ctrl+,`（工作台内 `Ctrl+,` 是**编辑器偏好抽屉**，
全局设置用 `Ctrl+Alt+,`）。

```
┌──────────────┬──────────────────────────────────────────────────────────┐
│ ─ 应用 ─      │  外观                                                     │
│ 外观          │  ──────────────────────────────────────────────────────  │
│ 语言与区域    │  主题     [浅色] [深色] [跟随系统]        ← §C8 分段控件   │
│ 快捷键        │  界面缩放 [────●────] 100%   [100]        ← §C9 + §C5     │
│ ─ 数据 ─      │  密度     [紧凑] [标准] [宽松]                            │
│ 数据目录      │  减少动效 ☐ 覆盖系统设置                                   │
│ 备份与恢复    │  非打印字符 ☐ 显示空格、制表符与换行                        │
│ 更新          │  ──────────────────────────────────────────────────────  │
│ ─ 引擎 ─      │  预览                                                     │
│ 引擎白名单    │  ┌──────────────────────────────────────────────────┐    │
│ ─ 其他 ─      │  │ 418 ◧ The Supplier shall…  │ 供应商应采取…      │    │ ← 实时预览
│ 教程与示例    │  └──────────────────────────────────────────────────┘    │
│ 关于与许可    │                                                          │
└──────────────┴──────────────────────────────────────────────────────────┘
```

### 1.3 各组内容

| 组 | 内容 |
| --- | --- |
| **外观** | 主题、界面缩放（80–160%）、密度档、减少动效、非打印字符。**带一个实时预览的段落行**——用户能立刻看到密度与缩放的效果 |
| **语言与区域** | UI 语言（zh-CN / en-US）、日期格式、数字格式。切换语言立即生效（不要求重启） |
| **快捷键** | 预设（默认 / Trados / memoQ）+ 完整可编辑表。每行：动作、分类、当前键、冲突提示。冲突时**内联标红并指出与谁冲突**。`恢复默认` 与 `导入/导出键位` |
| **数据目录** | 当前路径（可复制、可在文件管理器中打开）、剩余空间、`更改位置…`（迁移前自动备份并说明） |
| **备份与恢复** | 备份历史列表（时间、体积、触发原因）、`立即备份`、`从备份恢复…`（二次确认 + 说明会覆盖什么） |
| **更新** | 更新模式（自动 / 提醒我 / 手动）、当前版本、检查更新、更新日志。**明确说明更新前自动备份数据**（PRD N-04） |
| **引擎白名单** | 允许的引擎列表（PRD M-03）。空列表 = 不限制。措辞朴素，**不做成合规卖点** |
| **教程与示例** | `重新开始教程`、`打开示例项目`、文档链接 |
| **关于与许可** | 版本、构建号、引擎核版本、开源许可证、第三方组件清单（含字体 OFL 声明）、遥测状态（`已关闭`） |

### 1.4 设置页纪律

- 每个设置项**必须有一行说明它的后果**，不能只有标签。
- 立即生效的用 §C7 Switch；需保存的用 §C6 Checkbox + 底部 `保存` 条。**不混用。**
- 破坏性设置（更改数据目录、从备份恢复）走 §F2 Confirm Dialog。
- 页面可深链：`settings/shortcuts` 等，便于从别处的 `前往设置 →` 直达具体组。

## 2. 首次运行教程

### 2.1 推翻了什么

实拍 `01-first-run-tutorial.png` / `TutorialOverlay.tsx`：全屏覆盖式教程。
问题：覆盖层挡住了它正在介绍的东西。

### 2.2 新形式：锚定式引导（Coach Marks）

- 每一步是一个 §A4 Popover，**锚定到它正在介绍的真实控件上**（CSS Anchor Positioning），
  并给该控件加一圈 2px `--signal` 高亮环（Active Axis 的一种驻留态）。
- 背景**不加遮罩**（遮罩会让用户看不到上下文）。改为把非目标区域降到 92% 亮度。
- 每步内容：一句话说明 + 该动作的快捷键 + `下一步` / `跳过教程`。
- 步进指示：`2 / 5`（Mono）+ 一条 4px 进度条。

### 2.3 五步（对应最短成功路径，PRD 目标"30 分钟端到端"）

| 步 | 锚定 | 说明 |
| --- | --- | --- |
| 1 | `新建项目` 按钮 | `从这里开始。或者先打开示例项目看看。` + `[打开示例项目]` |
| 2 | 文档切换器 | `项目里的文件在这里切换。` |
| 3 | 译文单元格 | `在这里输入译文，Ctrl+Enter 确认并跳到下一段。` |
| 4 | Stack 匹配区 | `翻译记忆与术语命中显示在这里，Alt+1 插入第一条。` |
| 5 | Document Matrix | `这一列是整个文档的段落。空心未译、实心已确认、红点有问题。点它可以跳转。` |

第 5 步是**新装置的必要说明**——不解释的话 Document Matrix 会被当成装饰。

### 2.4 规则

- 可随时 `Esc` 跳过；跳过后不再自动出现，可从设置重新开始。
- 教程**不阻塞**任何操作：用户在教程进行中可以正常工作，Popover 跟随。
- 教程状态持久化（现有 `tutorial-state.ts` 契约保留）。

## 3. 草稿恢复

### 3.1 定位

崩溃恢复是 P0（PRD N-07 / C-17：`段确认即时持久化，崩溃零丢失`）。
这个对话框是产品可信度的关键一屏——用户在这里判断"我的东西还在不在"。

### 3.2 形式：§A5 Dialog（`lg` 760px），这是少数必须阻断的场景

```
┌────────────────────────────────────────────────────────────────────┐
│ ▛▀▀▀▀▀▀▀▀▀▀▀▀▀▀▜                                                   │
│ ▌ 恢复未保存的草稿 ▌                                                 │
│ ▙▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▟                                                   │
│ 上次退出时有 3 段译文没有写入。它们保存在本地草稿日志里。              │
├────────────────────────────────────────────────────────────────────┤
│ ☑ 段 418   Master Services Agreement.docx          2 分钟前          │
│   草稿  供应商应采取商业上合理的管理、技术和物理安全措施。              │
│   当前  （空）                                                       │
│ ──────────────────────────────────────────────────────────────────  │
│ ☐ 段 502   Master Services Agreement.docx          2 分钟前  ⚠已过时 │
│   草稿  保留期为 30 天。                                             │
│   当前  保留期为 30 个日历日。   ← 该段在别处被改过，恢复会覆盖         │
│   §D8 词级 diff                                                     │
├────────────────────────────────────────────────────────────────────┤
│ [全部丢弃…]              [复制选中草稿到剪贴板]      [恢复选中的 1 段] │
└────────────────────────────────────────────────────────────────────┘
```

| 项 | 规格 |
| --- | --- |
| 过时草稿 | `stale`（当前修订 ≠ 期望修订）→ **默认不勾选** + `⚠已过时` + 显示当前值的 §D8 diff |
| 恢复 | 逐条恢复，失败的条目保留在列表里并显示原因，不整体失败 |
| 丢弃 | `全部丢弃…` 是 `danger` + §F2 二次确认（`丢弃后无法找回`） |
| 复制 | 提供"复制到剪贴板"这条逃生通道——即使恢复失败，用户也能拿到文本 |
| 引擎断开时 | 若无法读取权威修订，**不做过时判定**，全部标 `无法校验`，默认不勾选，并说明原因 |

## 4. 全局搜索

统一到**命令面板**（`06-shell-navigation.md §3`）与**首页搜索 Tab**（`screens/project.md §1.4`）。
删除工作台顶部的独立搜索框。

| 入口 | 范围 |
| --- | --- |
| `Ctrl+K` | 命令 + 跳转 + 文档 + 段落（`#` 前缀） |
| `Ctrl+Shift+K` | 直接进入"跨项目内容搜索"模式（等同首页搜索 Tab） |
| `Ctrl+F` | 当前文件内查找替换（工作台抽屉） |
| `Ctrl+Shift+F` | Concordance（结果进 Stack 匹配区） |

**结果呈现**：按项目 → 文档 → 段落三级分组，每条显示段号、命中片段（前后各 30 字符）、
命中词 `--signal-ink` 加粗、来源标记。点击直达并在目标位置做 220ms 定位高亮。

## 5. 三态规范（加载 / 空 / 错误）

### 5.1 加载

| 时长 | 呈现 |
| --- | --- |
| < 300ms | **什么都不显示**（避免闪烁） |
| 300ms – 3s | §D5 Skeleton，与最终布局同形 |
| > 3s | Skeleton + 一行 `--t-meta` 说明正在做什么（`正在打开 1,248 段…`） |
| 可确定进度 | §D3 确定性进度条 + Mono 百分比 + `在后台继续`（若可后台） |

**禁止**：圆形 spinner（`LoaderCircle` + `.spin` 需全部替换）、不确定进度条冒充确定进度、
空白页面。

### 5.2 空态

§D6 结构，三类：

| 类 | 例 |
| --- | --- |
| **从未有过**（首次） | `还没有项目` / `导入一份文档就能开始，成果会自动沉淀到资产库` / `[新建项目] [打开示例项目]` |
| **筛选后为空** | `当前筛选没有匹配的段落` / 列出**生效中的筛选条件** / `[清除筛选]` |
| **前置条件未满足** | `还没有挂载可写入的翻译记忆库` / `确认的译文需要一个可写库才能沉淀` / `[挂载库]` |

**禁止**：`暂无数据`、只有图标没有下一步、氛围散文、插画吉祥物。

### 5.3 错误

四段式（§F5）：**发生了什么 → 你的工作怎么样了 → 一个恢复动作 → 技术细节（折叠）**。

| 场景 | 文案骨架 |
| --- | --- |
| 引擎进程退出 | `引擎连接中断` / `正在重连。已输入的译文保存在本地草稿中，不会丢失。` / `[重试]` / `退出码、日志路径` |
| 导入失败 | `无法导入 <文件名>` / `项目未被修改。` / `[重试] [跳过这个文件]` / `过滤器名、错误位置` |
| 导出失败 | `导出未完成` / `原文件未被覆盖。` / `[重试] [更改输出位置]` / `阶段、路径、错误` |
| AI 请求失败 | `请求失败：<可读原因>` / `未消耗配额。` 或 `已消耗 n token。` / `[重试] [换配置档]` / `HTTP 状态、请求 ID` |
| 数据库损坏 | `工作区数据需要修复` / `已自动备份到 <路径>。` / `[尝试修复] [从备份恢复]` / 诊断 |
| 权限不足 | `没有写入 <路径> 的权限` / `没有数据被修改。` / `[选择其他位置]` / 路径与权限位 |

**禁止**：`ABORT` / `MISSION FAILED` / `Oops!` / 只有错误码没有人话 / 不说明数据安危。

## 6. 键盘与焦点的系统级保证

| 保证 | 说明 |
| --- | --- |
| 焦点可见 | `:focus-visible` 全局 2px `--signal` + 2px 偏移。**永不 `outline: none` 而不给替代** |
| 焦点归还 | 任何叠层（Popover / Dialog / Drawer / Toast 动作）关闭后，焦点回到触发元素 |
| 焦点陷阱 | 仅 §A5 Dialog 使用（现有 `useFocusTrap.ts` 契约保留）。Drawer **不**陷阱（可 Tab 出去） |
| 跳转链接 | 每个 Surface 顶部有隐藏的 `跳到主内容` / `跳到段落网格` |
| 路由后焦点 | Surface 切换后焦点移到新 Surface 的主区域容器（`tabindex="-1"`），并由 `aria-live` 播报页面名 |
