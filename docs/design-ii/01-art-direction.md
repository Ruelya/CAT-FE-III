# 01 · 艺术方向

## 1. 上一代为什么失败

对照 `.trellis/workspace/frontend-visual-review/` 的实拍截图与 `docs/ChatGPT Image 2026年7月17日 20_04_16.png` 母版，
失败不在"执行不到位"，而在**方法错了**：

> 上一代的做法是「先搭一个通用后台，再在顶部贴一条彩条、在空白处铺一片点阵」。
> 于是彩条和点阵变成两个**可以被删掉而界面毫无损失**的贴纸。凡是可以被无损删除的，就不是设计。

具体病灶：

| 病灶 | 实拍证据 | 根因 |
| --- | --- | --- |
| 工具条是杂物抽屉 | `13-workbench-default.png`：状态筛选 + 文内搜索 + Exact TM + 4 个图标 + Issue 导航 + Confirm 挤在 44px 一行，标签被裁切（"Issue" 被搜索框压住） | 没有做频率分层，所有东西都想常驻 |

## 2. 从《孤星》里到底该继承什么

继承**形式方法**，不继承**世界观**。以下事实来自 `docs/design-research-retrofuturism.md` 与本轮复核
（HalfACupOfRice《The Visual Design of Arknights Lone Trail》专题分析）：

### 2.1 可继承的六条形式方法

1. **构成主义 → 风格派 → 包豪斯 → 国际主义排版风格**这条谱系，落地为：
   **栅格系统 + 非对称配置 + 大量留白 + 一律左对齐 + 几何抽象**。
2. **几何抽象**：复杂对象一律压缩为圆、环、直线、三角。
   证据：孤星的莱茵实验室先驱计划标志＝一条渐细线 + 一段弧（火箭尾迹）；
   关卡图标把复杂场景压成线/圆/三角以便小尺寸可读；
   Visual Report 的圆环用**变化的线宽**表达运动。
3. **非彩色大底**：大面积暖白/黑/灰建立理性、工业、档案式空间；颜色只在关键处爆发。
4. **色彩纪律**：调色板 = **三原色 + 非色（白/黑）+ 一个机构色（橙）**，
   且各色相都被"做旧"（偏离纯原色），模拟旧彩照与旧印刷品的色相。
   界面图形与文字**几乎只用非色与橙**，原色只做点缀、打破单调。
5. **打孔矩阵**：遍布孤星的规则圆点阵，其形式来源是**打孔卡 / 打孔纸带（早期计算机的数据存储介质）**。
   —— 这是本次重构最重要的一条继承，见 §3.2。
6. **几何无衬线**：Futura 谱系（1927，Paul Renner），字形由圆/方/三角构成，笔画近乎等宽，
   "看起来不像人写的，像机器造的"。NASA 阿波罗计划仪表盘与月面纪念铭牌用的就是它。

### 2.2 明确不继承的东西

- 一切叙事性/哲学性表述（"科学乐观与深空孤独的张力"之类）。**本产品是干活的工具，不承担情绪叙事。**
- 「翻译项目 = 一次航天任务」的术语映射表（载荷 / 飞行记录 / 制导 / GO-NO-GO / 发射序列）——**整表作废**，
  连内部构思阶段也不再使用，因为它每次都会渗回文案。
- 明日方舟本体的通用机制：毛玻璃、警戒条纹、网点颗粒、暗角、工业噪点、CRT 扫描线。**一律不用。**
- 航天符号：NASA 徽标模仿、任务徽章、宇航员、星空背景、行星、驾驶舱框架。**一律不用。**

## 3. 七条设计命题

这七条是本次重构的全部主张。后续所有文档都是它们的展开。

---

### 命题一 · 层理即权限：亮度编码可编辑性

**主张**：非彩色大底不是一张纸，是**三层层理（Strata）**，亮度严格编码"这块区域能不能被你改"。

| 层 | 名称 | 含义 | 出现位置 |
| --- | --- | --- | --- |
| 最亮 | **Deck** | 你可以在这里打字/编辑/读长文 | 译文单元格、原文单元格、表单输入、文档预览页面、TM 条目正文 |
| 中 | **Frame** | 结构与元数据，只读、可点 | 面板头、列头、筛选栏、卡片底、列表分组 |
| 最暗 | **Ink** | 应用身份与命令面，不承载可编辑内容 | 顶部标识板、Index Spine、仪表条、模态遮罩、主按钮的对位面 |

**为什么这是可用性装置而非风格**：8 小时长时段使用中，用户最频繁的微判断是"这里能不能编辑"。
把它编码进亮度，用户不需要读边框、不需要 hover 试探。它也让"装饰不得压在可编辑文本上"这条老规矩
从一句自律变成一条**结构上不可能违反**的规则——装饰活在 Frame/Ink，可编辑内容活在 Deck。

**推论**：任何"把输入框做成透明贴在暗底上"的设计一律违规。任何"在 Deck 上铺纹理"的设计一律违规。

---

### 命题二 · 彩条是脊柱，不是贴纸

**主张**：五色 Translunar Band 从"顶栏下缘 6px 横带"改为**窗口最左缘 4px、贯穿全高的垂直脊柱**，
固定顺序自上而下：Burnt Orange → Solar Ochre → Lichen Green → Instrument Teal → Dusk Blue，各占 1/5 高度。

**为什么**：

1. 横带贴在顶栏下缘时，它是"顶栏的下划线"，可以删；
   竖立在窗口左缘并贯穿全高时，它是**窗口的边界本身**，删掉会露出结构断面。
2. 它成为全应用唯一一个**跨 Surface 恒定不变**的元素。切换页面时其余一切都换，只有脊柱不动——
   这给了空间连续性一个物理锚点（对应研究里的"同一张画布上展开另一层"）。
3. 它变成页面转场的**发令元素**：转场时脊柱做一次 240ms 的亮度扫掠（自上而下），
   内容随后进入。一个零成本、高辨识度的签名动作。

**纪律**：整屏仅此一处完整彩条。压缩回显（同序五色）只允许出现在：应用标记、项目缩略图、
文档预览把手左端——三者互斥，一屏最多再出现一次。彩条各色**永不**用于按钮、状态、图表、
链接、焦点。彩条**不进入**深色主题的高亮区（深色下整体降亮 10%，见 §02.4）。

**覆盖率验算**：1250×744 视口下，4×744 = 2,976px² ／ 930,000px² = **0.32%**，低于 0.8% 预算。

---

### 命题三 · 圆点矩阵是数据基底，不是填空纹理

**主张**：把圆点矩阵拆成两个**外观必须可区分**的等级。

**Live Matrix（活性矩阵）** —— 承载真实数据、可交互、有焦点。
形式依据是打孔卡/纸带：一格 = 一条记录，孔位 = 记录状态。本产品的天然对应物是**段落**。

- **Document Matrix**（主工作台左侧 28px 竖条）：文档全部 N 个段落各占一个点。
  空心=未翻译 / 半填=草稿 / 实心=已确认 / 红点=有 QA 错误 / 橙环=当前段。
  视口括号标出屏上范围。点击跳段，拖拽滚动。**它直接取代原生滚动条。**
- 同一装置复用于：TM 库健康度、QA 分布、批处理进度、资产养护批次、对齐置信度、
  项目文件段落构成、reimport 差异图。

**Inert Matrix（惰性矩阵）** —— 纯图形，不可交互，不可聚焦，不编码任何值。
- 对比度必须**低于屏上任何一条边框**；点径更小、间距更密（1px / 6px pitch，Live 是 3px / 9px pitch）。
- 只允许出现在：面板头未使用的一半、外侧 gutter、预览边缘、仪表条端帽、空态大场。
- 一屏最多三处，合计覆盖 < 3%。永不动画（转场时可被遮罩揭示一次）。

**为什么这是可用性装置**：1,248 行虚拟列表里，用户最缺的信息是"我在哪 / 还剩多少 / 问题在哪扎堆"。
Document Matrix 一次性回答三个问题，并且它长得**就像**这个产品的主题纹理。
这是本次重构里"艺术=功能"最直接的一处兑现。

---

### 命题四 · 全应用只有一条橙色轴线

**主张**：信号橙不是"到处点缀的强调色"，而是**一个连续的对象**——**Active Axis（活动轴）**：
一条 2px 橙线，同一时刻全屏只有一条，永远表示"你在这里"。

它会**移动**：从活动行的前缘 → 到被聚焦的标签下缘 → 到向导当前步 → 到聚焦输入框的左缘 →
到命令面板选中项的前缘。移动用 View Transition 做 FLIP，160ms。

**为什么**：密集界面里最贵的认知成本是"焦点在哪"。传统做法用 5 种不同的高亮（选中行底色、
tab 下划线、focus ring、按钮态、列表高亮）分别表达，用户要学 5 套。
一条会移动的轴线把它压成 1 套，并且移动过程本身告诉用户焦点去了哪。

**推论与例外**：
- 主按钮填充是橙色**面**，不是轴；面和轴可同屏，但一屏只有一个主按钮。
- 键盘焦点环（2px 橙 + 2px 偏移）是轴的"驻留态"，同一时刻它与轴合一。
- 橙色总覆盖 ≤ 1.5%（含按钮面）。
- **橙面上一律用墨色文字，永不用白色**（见 §02.2 对比度验算：白字仅 3.6:1 不合规，墨字 4.9:1 合规）。
  这同时把主按钮做成了构成主义海报里的"橙底黑字"，比白字更接近来源。

---

### 命题五 · 板块与接缝：没有浮层，只有对接

**主张**：界面由**刚性板块（Plate）**沿一套**可见接缝（Seam）**系统对接而成。
不用阴影分层，不用圆角卡片，不用悬浮胶囊。

- 接缝三档：**结构缝** 1px @34% ／ **面板缝** 1px @18% ／ **内部缝** 1px @10%。
- 板块之间**永远直接对接**，不留 gap，不做圆角，交界处就是缝。
- 唯一允许的"浮"是真正的临时层：popover、菜单、模态、toast——它们用**一级**暖调阴影 + 遮罩，
  且必须锚定在触发源上（CSS anchor positioning）。
- 45° 切角（`corner-shape: bevel`）**每屏最多一处**，只用于该屏的品牌板（Band Plate / 标识板 / 面板主标题块）。

**为什么**：浮层堆叠是密集工具最大的视觉噪声来源（对照 `21-qa-review.png`：QA 卡片、面板、行、
预览四层圆角矩形彼此嵌套）。板块-接缝制去掉了 3 层嵌套边框，把结构信息交给缝的**权重**，
省下的对比度全部留给内容。这也是国际主义排版风格的原生做法。

---

### 命题六 · 频率分层：常驻的只有高频

**主张**：控件位置由**使用频率**决定，而非由"属于哪个功能模块"决定。三档：

| 档 | 判据 | 承载 | 位置 |
| --- | --- | --- | --- |
| **F1 常驻** | 每分钟 ≥1 次 | 状态筛选、确认、上/下段、TM 插入、术语插入、问题导航 | 筛选栏 + 行内 + 键盘 |
| **F2 一键可达** | 每小时数次 | 查找替换、批注、拆分合并、运行 QA、导出、文档切换、预览开合 | 命令面板 / 单一入口按钮 / 快捷键 |
| **F3 按需** | 每项目数次 | 引擎配置、快捷键预设、简繁配置、插件、互操作、任务包、归档 | Surface 页面 / 设置 |

**推论**：现工具条里的 `⌘`、放大镜、撤销、重做、批注 4 个图标**全部移出**（→ 命令面板 + 快捷键）；
`Exact TM` 移入 Stack 面板头；`Confirm` 移到行内 + Ctrl+Enter，不占工具条。
筛选栏因此从 8 组控件降到 3 组，标签不再被裁切。

---

### 命题七 · 动效是空间说明书

**主张**：动效不是装饰，是**告诉用户新东西从哪来、旧东西去了哪**。全应用只有**一个动作词汇**：
沿结构缝行进的**遮罩推移（Seam Wipe）**。

页面转场、面板展开、预览升起、矩阵点燃、行确认、AI 流式输出——全部表述为"某条缝上的一次推移"。
方向即层级：**向下/向右 = 深入，向上/向左 = 返回**。

**为什么统一到一个词汇**：密集工具里动效最容易变成噪声。当所有动效共享同一几何来源（缝）
和同一方向语义时，它们叠加起来仍然可读，而且实现成本极低（`clip-path` + `transform`，
或直接 View Transition 的 `::view-transition-old/new` 分组）。

**预算**：同一时刻最多 2 个主要动画；网格文本永不做逐字动画；除真实进行中的操作外，禁止任何循环。

## 4. 密度与表达的分区纪律（沿用并收紧）

| 区域 | 密度 | 表达强度 | 说明 |
| --- | --- | --- | --- |
| 段落网格单元格内部 | 8/10 | **1/10** | 只有文字、标签胶囊、状态方灯。零装饰、零纹理、零线条 |
| 网格外框、列头、Document Matrix | 7/10 | 6/10 | 缝、刻度、活性矩阵 |
| Stack 面板 / 预览坞 | 6/10 | 5/10 | 面板头允许惰性矩阵 |
| 顶部标识板 / Index Spine / 仪表条 | 5/10 | 8/10 | Ink 层，身份表达集中区 |
| 项目首页 / 向导 / 洞察 / 空态 | 4/10 | 9/10 | 大留白、非对称、大字号裁切、几何构图 |

## 5. 禁止清单（硬门禁）

**图形**
- ❌ 圆角卡片堆叠（>2 层嵌套边框）、投影分层、玻璃拟态、发光、斜面、渐变作装饰
- ❌ 胶囊化一切（药丸只留给筛选 chip 与标签）
- ❌ 悬浮在两个板块之间的控件（上一代母版的双箭头胶囊即此类）
- ❌ 装饰性坐标串、假遥测、无解释百分比、无意义仪表盘、非功能开关
- ❌ 可读的装饰性标签（`MODULE 02` / `FIG. 04` / `SYSTEM NOMINAL`）
- ❌ 警戒斜纹作通用装饰（只允许出现在阻断性错误横幅的窄前缘）
- ❌ 圆形 spinner、emoji 图标、自定义光标、扫描线、颗粒噪点、暗角

**色彩**
- ❌ 橙色白字；❌ 彩条任一色用于状态/按钮/图表；❌ 状态色用于装饰
- ❌ 深色主题＝反色；❌ 冷蓝灰面板；❌ 荧光绿/琥珀 CRT 屏

**文案**
- ❌ 航天术语替换 CAT 术语；❌ 口号、氛围句、伪系统闲聊
- ❌ AI 营销词（Elevate / Unleash / Seamless / Next-gen / Intelligent workflow）
- ❌ `ABORT` / `MISSION FAILED` 式戏剧化错误文案
- ❌ Acme / John Doe 式假名，假整数，虚构模型版本号

**字体**
- ❌ Inter / Roboto / Arial 作为**主动选择**（作为最终 fallback 可以）
- ❌ Orbitron / Audiowide / Eurostile Extended 等科幻陈词
- ❌ 通用衬线体
