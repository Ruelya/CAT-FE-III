# 品牌色带

## 定义

固定顺序的五条扁平相邻色带。

| 顺序 | 名称 | Hex |
| --- | --- | --- |
| 1 | Burnt Orange（橙） | `#D9562B` |
| 2 | Solar Ochre（赭黄） | `#D29A2E` |
| 3 | Lichen Green（苔绿） | `#87904A` |
| 4 | Instrument Teal（仪表青） | `#4F8076` |
| 5 | Dusk Blue（暮蓝） | `#526F86` |

上述为**品牌标识**用色，仅用于应用标题栏左侧的品牌标记，顺序固定不可调换。

## 界面数据色板

品牌色带同时承担界面中的**分类数据色板**职责：进度分段、QA 严重度分级、文档类型
标识、图表序列。标识用的原始色值在界面背景上达不到对比度门槛，因此按主题各派生
一套，并刻意错开明度，使其在灰度打印与色觉障碍条件下仍可区分。

### 浅色主题

## 使用规则

- 品牌色带**不用于任何可交互控件**。交互强调色只有一个：高级棕
  `--color-accent`。
- 堆叠进度条的相邻分段之间留 1px 父表面色缝隙，因此相邻序列之间不需要互相满足对
  比度；每个序列另配文字标签或图例。
- 任何含义都不得只靠颜色传达，必须同时有文字，空间允许时再加图标。
- 语义色（成功 / 警告 / 错误 / 信息）与品牌色带、强调色种子三者互相独立，用户自
  定义强调色不会改变语义色。

完整色板、对比度实测值与校验方式见 `.trellis/spec/frontend/design-language.md`
第 2 节。
