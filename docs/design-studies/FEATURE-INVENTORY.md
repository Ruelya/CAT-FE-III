## 2. 左栏（项目资源）

- 项目名、语言对（en-US → zh-CN）、项目总进度条（已确认/草稿分段着色 + 百分比）。
- 文件搜索框（本地过滤，过滤时目录强制展开）。
- IDE 式文件树：嵌套目录（`docs/manual`、`app/locales`）、折叠 chevron、目录/文件类型图标（docx/json）、缩进导线、活动文件高亮、右对齐每文件确认百分比、QA 未解决数角标；`格式 · 确认 x/y · 草稿 · QA` 收进行 tooltip；点击打开标签页；两步移除（悬停 × → 确认移除/取消）。
- 筛选 chips：未译 / 草稿 / 已确认 / QA / 锁定 / 有术语 / 有标签（可点选、可关闭，作用于句段格）。
- 拖放导入区（虚线落区 + 选择文件按钮，同导入对话框一个入口）。
- 项目详情：名称 / 源语言 / 目标语言 / 创建时间 / 文件数 / 总句段 / 已确认句段。

## 3. 中栏（双语句段格）

- 文档标签页（可关闭；关闭标签不删文档）。
- 格列：`#`、源文（只读可选中）、译文（活动行挂 textarea 编辑器）、状态。
- 状态列：状态字形 ○ 未译 / ✎ 草稿 / ✓ 已确认；锁定 🔒 独立字形；QA ⚠n 叠加；来源 chip（`100 TM` 精确 / `88 TM` 模糊 / `AI`，人工改动后转灰保值，tooltip 列 状态/来源/分值/模型）；行 ⋯ 菜单（复制源文 / 清空译文 / 锁定|解锁）。
- 占位符 token（`{name}`、`%d`、`<b>`、`&amp;`）渲染为 chip；QA 缺失/多余 token 描红。
- 编辑语义：输入即草稿（自动保存）；Esc 退出编辑不丢字；空译文确认被拒绝并报告；锁定行编辑器不挂载。
- 格工具栏：状态筛选、活动筛选 chips（逐个 × 清除）、可见/总句段计数。
- 查找/替换小部件（Ctrl+F / Ctrl+H）：查找框 + `n 段` 计数、上一个/下一个、替换为、替换 / 全部替换、含已确认 复选框、Esc 关闭；全部替换如实报告跳过的已确认/锁定句段。
- 空态：暂无文档 / 没有打开的文档 / 该文档没有句段 / 没有符合筛选条件的句段。

## 4. 右坞（4 组，Ctrl+1..4）

**记忆**：活动句段 TM 命中（分值徽章 + 精确/模糊 + 记忆库名 + 应用为草稿，双击也应用）；下方 检索（检索词、文档内命中带 源文/译文 徽章与 定位句段、项目 TM 模糊命中区）。Tab 上实时最佳分值 chip。

**术语**：活动句段术语命中（源术语 → 多译法，首选/禁用 徽章，插入 按钮，禁用不可插入）；快速添加（源术语/目标术语/添加术语，写入首个可写术语库）；未挂载/无命中空态。

**QA**：标题带未解决计数 + 运行 QA；未解决按规则分组（组内按严重度 ⛔错误 / ⚠警告 / ⓘ提示）；每条：severity 字形、状态徽章（未解决/已忽略/已解决）、规则 id、本地化 message、证据（源 [] ≠ 译 []）、忽略 / 忽略同类 / 忽略本句 / 定位句段；引擎给出修复时显示 修复为：… + 应用修复；已忽略项可 恢复。Tab 上未解决计数 chip。

**AI**：上半 AI 辅助（已配置：AI 翻译 / AI 润色 / 取消请求，候选卡带 翻译候选/润色候选 徽章、标签完整/破损 校验、与当前译文的差异 diff、应用为草稿 / 拒绝；未配置：供应商下拉 11 家 + 模型 + Base URL + API Key + 保存配置，诚实 未配置 徽章）。下半 Agent 模式（任务指令、创建任务单并运行 / 取消运行、计划/TM/AI 草稿/失败/QA 未解决 计数、步骤流：规划/TM 预翻/AI 起草/质检/总结，状态徽章；awaitingReview 人工审核门：去工作台查看草稿 / 去导出…）。

## 5. 底部预览（可折叠，Ctrl+P）

- 校对视图：按结构块回填译文，未译回退源文并标注；图例 已确认/草稿/未译；点击句段跳回格内行；跟随活动句段。
- 版式视图（DOCX）：真实导出管线渲染；正在生成/重新生成/失败/已回填 n 个 状态；点击锚点跳句段。

## 6. 对话框（全部可从菜单/功能区打开）

1. **新建项目**：项目名称 / 源语言 / 目标语言 / 创建项目。
2. **导入文档**：选择文件…、分段方式（句子（SRX 规则）/ 段落）、选择 SRX 规则…（段落模式禁用）、取消 / 导入；成功后回存项目默认。
3. **项目设置**：项目信息（名称/语言对/保存）；导入默认（分段 + 默认 SRX）；质量检查（有错误时阻止导出 开关）；生命周期（归档/恢复 + 徽章）；翻译记忆（选库下拉「可写」标注 + 导入外部 TM… / 导出 TM…）；术语库（挂载列表：管理术语 / 导入 CSV/TBX… / 导出… / 卸载；未挂载列表：挂载；新建并挂载）。
4. **记忆库管理**：挂载列表（可写/只读、已停用、语言对不符 徽章；上移 / 下移 / 停用|启用 / 设为可写 / 重命名 / 卸载）；挂载已有（选择 + 挂载 / 删除，删除两步 + 连同条目删除 级联确认）；新建并挂载；条目浏览（选库 + 搜索 + 共 n 条 + 编辑/删除（两步）+ 分页 上一页/下一页）。
5. **术语库管理**：条目列表（源术语 → 译法，首选/禁用）；编辑（源术语/目标术语）；删除（两步确认）；删除单个译法。
6. **导出覆盖确认**：目标已存在，要覆盖吗？+ 路径 + 覆盖 / 取消。
7. **导出 QA 门拒绝**：存在 QA 错误，仍要导出吗？+ n 个错误未解决：规则列表 + 仍要导出 / 取消。
8. **引擎不可用闸门**：翻译引擎已停止 / 编辑已锁定 / 最后错误 / 重新启动引擎；下层界面 inert。

## 7. 状态栏（24–32px，常显）

状态消息（静默替换，无横幅）· 句段 当前/总数 · 已确认 · 草稿（点击→筛草稿）· 剩余 · 字数（引擎口径，CJK 按字）· QA（点击→筛 QA）· 进度条+% · 行列 行:列 · INS · 引擎状态点 + `engine 0.x · pid`。

## 8. 状态与词汇表

- 句段状态：未译 / 草稿 / 已确认；正交：锁定。
- 来源：TM 精确（分值）/ TM 模糊（分值）/ AI（模型，无分值）/ 人工（无 chip）；改动后灰化。
- QA 严重度：错误 ⛔ / 警告 ⚠ / 提示 ⓘ；QA 状态：未解决 / 已忽略 / 已解决。
- 引擎：就绪 / 启动中 / 重启中(n) / 已停止。
- Agent：运行中 / 等待人工审核 / 已取消 / 失败；步骤：done/failed/skipped。
- AI 辅助：未配置 / 已配置（供应商 · 模型）/ 请求中 / 候选 / 失败。

## 9. 场景（每稿内置 场景 切换器）

| 场景 | 呈现 |
|---|---|
| 空项目 | 项目列表空态 + 新建项目 |
| 已导入 | 满格工作台（混合状态 + token + 来源 chip） |
| 确认写入 TM | 刚确认的行 + 状态栏写入报告 + 记忆坞新 100% 条目 |
| 锁定行 | 🔒 行，编辑器拒绝挂载，功能区变 解锁句段 |
| 未改模糊 QA | qa.unedited-fuzzy 警告 + 行 ⚠ + 忽略/恢复 |
| AI 未配置 | AI 坞供应商表单 + 未配置 徽章 |
| Agent 待审核 | 步骤流 + 计数 + 人工审核门 |
| 导出门 | QA 门拒绝对话框（仍要导出 / 取消） |
| 引擎闸门 | 翻译引擎已停止 + 错误码 + 重新启动引擎，下层 inert |
