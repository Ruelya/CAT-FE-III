# Translunar CAT 设计研究（四个方向）

四个**互相独立**的桌面 CAT 工作台设计研究。每个研究都是一份自包含的 `index.html`（内联 CSS/JS，本地 woff2 字体），在浏览器里直接打开即可交互：行选择、行内编辑、确认（⌘/Ctrl+Enter）、记忆插入、术语、QA 修正、面板切换、命令面板（⌘/Ctrl+K）、可拖拽分栏。所有动效都是**因果动效**（确认闪光、面板升起、匹配插入、弹簧展开），没有无限循环的装饰动画，全部尊重 `prefers-reduced-motion`。

这些研究是对现行 INSTRUMENT 外观（IBM Plex、冷蓝灰、#1743ae、2/4px 圆角、发丝线、24px 状态栏）的**有意识拒绝**，不是换色。四个方向在版面语言、字体系统、色彩纪律、动效物理上彼此正交。

| 方向 | 路径 | 打开方式 |
| --- | --- | --- |
| 排字房（印刷编辑部） | `docs/design-studies/folio/index.html` | 浏览器直接打开 |
| 夜航（调色间暗色） | `docs/design-studies/nocturne/index.html` | 同上 |

每个目录下的 `shots/` 存有关键截图：完整工作台、确认动效、命令面板、QA 面板交互。

## 一、排字房（Folio）

**Design Read**：把双语网格读作对开折页的排字台，为文学与出版译者服务；原文栏是已排定的校样，译文栏是译者的活字盘，唯一的强调色是校对红铅笔。

- **字体**：Playfair Display（报头）、Newsreader（正文栏，旧式数字用于段号）、Libre Franklin（界面 chrome，报纸血统的 grotesque）、中文回退 Noto Serif SC。
- **版面语言**：牛津双线（粗上细下）作为报头分界；左栏目录用点线引导符对齐页码式的百分比；右侧资源栏是"旁注"，记忆命中排成脚注体例；底部状态栏是版记。
- **签名交互**：活动行的页边空白浮出红色指读符（manicule ☞）；确认是一次"压印"，铅笔灰的草稿文字落成墨黑，状态词盖上"已排 ✓"；QA 是校对红笔圈，一键把"版框"改成术语库的"夹框"。
- **为什么不是 slop**：没有卡片、没有阴影、没有圆角、没有渐变；密度靠字号与行距而非框线堆叠；红色只出现在"校对"这一个语义上。纸色与墨色是印刷情境下的诚实选择，不是"温暖 SaaS 米色"。
- **绝不上线的部分**：正文 15.5px 衬线用于长时段作业会累，真实产品需要一档"工作字号"；纸面噪点在低端屏上会显脏，需要按 DPI 降级。

## 二、夜航（Nocturne)

**Design Read**：把工作台读作调色间的控制台，为夜班本地化窗口服务；中性炭灰环境光（刻意无蓝偏），一盏钨丝灯是唯一工作光，完成态是安静的磷光绿。

- **字体**：Archivo（界面与正文）、Fragment Mono（所有数字：段号、时码、百分比），中文回退 Noto Sans SC。
- **版面语言**：顶部是"卷"（filmstrip）：每段是一个剪辑块，宽度按词数分配，状态用填充表达，活动段是发光的钨丝块，点击即跳段。这是签名导航，把"文档进度"变成可直接抓取的物理对象。底部状态栏是走带（transport）读数。
- **签名交互**：确认时行脊从钨丝色扫到磷光绿，卷上的剪辑块同步填充；记忆命中带一条表头电平条（meter），宽度即匹配率；命令面板是中央控制台，`>` 提示符。
- **为什么不是 slop**：不是 VS Code 深色 + 蓝强调；黑是中性的（调色间的环境要求），强调色只有一个且有物理隐喻（钨丝灯）；绿只表示"已定"这一个语义；数字全部等宽、全部可对齐。
- **绝不上线的部分**：纯黑环境在明亮办公室里对比过强，真实产品需要一档明度提升；剪辑块在千段文档下需要聚合成分组条。

## 三、清水混凝土（Béton）

**Design Read**：把工作台读作工地办公室的终端，为工程技术翻译服务；混凝土浇筑面、墨线、橡皮图章，零圆角零柔和，唯一的暴力强调色是安全橙。

- **字体**：Anton（图章与段号钢印数字）、Space Grotesk（界面）、Space Mono（读数），中文回退 Noto Sans SC。
- **版面语言**：2px 与 3px 的墨线分割板面；文件清单是配料单（编号钢印 + 等宽数字）；状态是旋转的橡皮章："合格"（墨线章）、"在建"、"未译"（虚线章）、"缺陷"（橙章）。骨料噪点铺在固定层上。
- **签名交互**：确认是一次盖章动作，图章从 2.4 倍缩放砸下、一帧回弹、落定在 -3°；面板切换是跳切（无滑动，机械咔嗒）；命令面板是一块从上方硬落的板（两段硬弹）。按钮有 3px 实体偏移影，按下时物理位移抵消。
- **为什么不是 slop**：不是"新粗野主义彩虹"；只有混凝土、墨、橙三种材料；影子是实体偏移而非高斯模糊；动效全部 90 到 240ms 的硬切，没有缓入缓出的黏腻感。
- **绝不上线的部分**：旋转图章在整页大量出现时会降低扫读效率，真实产品只应保留"缺陷"章；Anton 段号占宽较大，长文档需要收窄。

## 四、弹机（Kinetic）

**Design Read**：把工作台读作一台硬件乐器，为键盘长驻的职业译者服务；瓷白机身、炭黑键床、一个信号绿，所有状态迁移骑在真实阻尼弹簧上（质量-弹簧模拟采样成 CSS `linear()` 曲线，不是随手写的 bezier）。

- **字体**：Familjen Grotesk（界面）、Azeret Mono（读数与键帽），中文回退 Noto Sans SC。
- **版面语言**：行是圆角 10px 的实体键位；右栏匹配是"弹匣"卡带，逐个弹簧入场；顶部进度是物理推子（确认后旋钮弹簧滑动）；底部是键床。
- **签名交互**：**行即编辑器**。选中一行，它原地充气展开（grid-rows 弹簧），工具条从行内弹出（确认 / 插入匹配 / 复制原文）；确认时状态灯珠弹簧爆亮，本行泄气、下一行充气，弹簧被"传递"下去。底部键床的键帽会随真实按键**物理下沉**：按下 ⌘⏎，屏幕上的 ⌘ 和 ⏎ 两颗键帽同时压下。
- **为什么不是 slop**：动效全部有因果（反馈、状态迁移、层级交接），没有 Lottie、没有彩带、没有循环脉冲；绿色同时承担品牌与"确认"语义，全页唯一；弹簧参数是模拟出来的物理，过冲量与回稳时间可以被逐字号调校。
- **绝不上线的部分**：每次选行都展开工具条对高频用户是税，真实产品需要"安静模式"（工具条只在悬停或首次使用时展开）；键帽栏占 46px 高度，小屏应折叠为纯读数。

## 工程说明

- 字体以 woff2 子集（latin/latin-ext）打包在各研究的 `fonts/` 目录，`fonts.css` 中 `@font-face` 指向本地文件；中文依赖系统 Noto CJK（截图环境安装了 `fonts-noto-cjk`）。
- 四个研究共享同一套交互合同（行选择 / 编辑 / 确认 / 插入 / 面板 / 命令面板 / 分栏拖拽），因此可以公平对比气质差异。
- 截图由 Playwright 驱动真实交互后拍摄（确认动效在动画中途冻结帧），脚本不在仓库内。
