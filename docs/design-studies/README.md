# Translunar Workbench 设计稿（七个视觉系统，同一套完整信息架构）

七份可点击的桌面 CAT 工作台设计稿：三份 SaaS 产品向 + 四份艺术向（Fable Art）。信息架构**全量一致**——共用同一个假引擎（`saas-shared/app.js`）与同一份数据（`saas-shared/data.js`），差异只在视觉系统（每个目录一份 `theme.css`，Aurora 另有一个 `fx.js` 光场）。清单见 `FEATURE-INVENTORY.md`：先逐文件盘点真实桌面端（`apps/desktop/src`）的每条命令、坞、对话框、筛选与状态，再画图。

## 每份稿子都包含的 chrome（全量，非子集）

- **壳**：应用菜单条（文件/编辑/视图/项目/翻译/QA/帮助）；功能区（导入、导出译文、撤销、重做、确认、锁定句段、插入记忆、插入术语、预翻译、查找、查找下一个、替换、检索、运行 QA、预览、句段筛选框、命令搜索 Ctrl+K）；命令面板（命令 + 坞跳转 + 文档跳转，键盘上下 + Enter）；状态栏（状态消息、句段 n/总数、已确认、草稿跳转、剩余、字数、QA 跳转、进度条、行:列、INS、引擎状态点 + 版本 pid）。
- **左侧**：项目名、语言对、总进度条、项目详情；文件搜索（过滤时目录强制展开）；IDE 式文件树——嵌套目录、折叠 chevron、docx/json 类型图标、缩进导线、活动文件高亮、右对齐每文件百分比、QA 未解决数角标，`格式 · 确认 x/y · 草稿 · QA` 收进 tooltip，两步移除（悬停 × → 确认移除/取消）；拖放导入区；七枚筛选芯片（未译/草稿/已确认/QA/锁定/有术语/有标签），可点选可关闭，与网格工具条上的可关闭芯片联动。
- **中央**：双语网格（#、源文只读可选中、译文行内编辑器、状态字形 ○✎✓、锁形、来源芯片 100 TM / 88 TM / AI / 已修改置灰、QA 角标 ⚠n、占位符 token 芯片、行 ⋯ 菜单：复制源文/清空译文/锁定）；查找替换浮窗（Ctrl+F / Ctrl+H、n 段、F4 / Shift+F4、含已确认）；确认三和弦记录在确认按钮的 tooltip 上（Ctrl+Enter / Ctrl+Alt+Enter / Ctrl+Alt+Shift+Enter）。
- **右侧四坞**：记忆（命中 % + 库名 + 应用为草稿 + 检索 Concordance）、术语（命中 + 首选/禁用 + 插入 + 快速添加）、QA（按规则分组的严重度、忽略/忽略同类/忽略本句/恢复、修复为 + 应用修复、定位句段）、AI（供应商表单短标签、AI 翻译/润色、候选差异对比、标签完整性、Agent 步骤 + 人工审核门、诚实的未配置态）。
- **底部**：可折叠预览（校对视图按状态着色可跳转；版式视图 DOCX 纸面回填）。
- **对话框**：新建项目、导入文档（句/段/SRX）、项目设置（归档、有错误时阻止导出、TM/术语库导入导出选库）、记忆库管理（挂载/启用/可写/重命名/卸载/删除/条目分页编辑）、术语库管理、导出覆盖确认、导出 QA 门（仍要导出/查看 QA/取消）、引擎不可用闸门。

## Design Read

### SaaS Compact · 紧凑光亮

信息密度优先的操作台。Geist 的窄字面配 12.5px 界面字号，把 12 行句段、四坞、预览同屏放下；层级全部由发丝线与冷灰刻度承担，投影只留给浮层。唯一的靛蓝（`#3B5BDB`）承担选中、主按钮、模糊匹配三个语义；确认绿、草稿琥珀、错误红各管各的状态。坞标签用下划线指示激活，桌面软件的骨感。适合以键盘为主、日处理量大的专业译者。

### SaaS Comfortable · 舒适光亮

同一套架构放宽一档：13.5px 界面字号、10px 行距余量、圆角 8–12px、卡片带一层柔投影，底色是带冷绿灰调的中性刻度。强调色换成深青（`#0B7A68`）——出现频率最高的"应用为草稿/确认"动作因此更沉稳。坞标签是分段控件，文档标签是胶囊。适合长时段校对与审校角色，读起来不累。

### SaaS Dark · 暗色专注

中性偏蓝的暗灰刻度，浮层靠亮度分层（面板 → 卡片 → 浮窗逐级变亮）取代重投影；tooltip 反白保证可读。JetBrains Mono 承担全部数字与 token，暗底下等宽字符的辨识度最高。强调蓝 `#3E7DE8` 只用于选中与主动作，确认绿/草稿琥珀在暗底重新校准过对比度。版式预览是暗桌面上一张点亮的纸。适合夜间工作与深色系统偏好。

### Fable Art · Aurora 极光玻璃

一块 0.18 倍分辨率的 canvas 光场在窗外漂移——五团加色混合的径向光（青绿/靛/紫），CSS 放大成柔场；工作台是整片 `backdrop-filter` 磨砂玻璃，面板全部用透明度分层，浮层再加一层玻璃。唯一的薄荷强调（`#34E3B0`）承担主动作与活动行左缘光边，焦点环带辉光，卡片悬停浮起 1px。`prefers-reduced-motion` 时光场静止为单帧。动效是环境，不是干扰：网格、坞、对话框全部照常操作。

### Fable Art · Blueprint 蓝晒制图

普鲁士蓝坐标纸（6px/30px 双层网格衬底）上的白线制图。面板标题带引线短划，表头压双线（图纸明细表），活动行是左缘双线批注，对话框四角有制图 tick，落区与焦点环全部用虚线——像针管笔画出来的。主按钮是粉笔白反白，数字全部走 Martian Mono 读作测量值。坞标签激活时下划线从左画入（180ms）。CAT 工作台本来就是一张双语图纸，这套材质只是把这层隐喻画到底。

### Fable Art · Acid 画廊酸性

画廊灰白（`#F2F0E9`）上的黑色硬线：浮层 1.5px 实线描边 + 硬偏移投影，零圆角。国际克莱因蓝（`#0031AD`）承担全部主动作与焦点，酸性黄绿（`#D9FF4D`）只做选区、命中高亮与状态栏数字——颜色有分工，不抢语义。命名的东西（应用名、面板标题、对话框标题）用 Unbounded，正文与控件走 Familjen Grotesk。动效是版面的物理：按钮悬停整块面板位移 1px 而投影不动，按下反向塌进去；功能区动词在光标下呼吸 0.03em 字距。状态栏反转成黑色基座。

### Fable Art · Terra 陶土触感

矿物灰绿（`#E6E3DA`，石头不是纸）工作台上的软挤出陶土：控件上缘一线高光、底部一层土色投影，按下真的陷进去（inset）；输入框是按出来的凹槽。全部位移走带回弹的弹簧曲线（`cubic-bezier(.34,1.45,.5,1)`），对话框落位有一次 2px 过冲，文件树 chevron 也弹。赤陶（`#B85C38`）是唯一强调色，QA 的玫红与它刻意拉开色距。18px 对话框圆角、胶囊筛选芯片，Onest 的圆润字面配 Sometype Mono 的方正数字。

## Nielsen 对照

- **系统状态可见**：状态栏常驻消息 + 引擎点；确认/QA/导出每步都写状态行，重要事件加静默 toast；进度条在左栏、文档项、状态栏三处一致。
- **匹配真实世界**：全部译者动词（确认、锁定、预翻译、检索、术语、QA 门），来源芯片直接写 "100 TM / AI"。
- **用户控制**：Esc 逐层退出（菜单→面板→对话框→查找→编辑→筛选）；撤销/重做贯穿译文编辑；每个破坏性操作（移除文档、删除记忆库/条目/术语、覆盖导出）都有内联二次确认。
- **一致性**：同一命令在菜单、功能区、命令面板共用一套动词与快捷键；七份稿子控件语义完全一致。
- **防错**：空译文确认被拒绝并写明原因；锁定行不挂编辑器、行菜单相应禁用；QA 有错误时导出被门拦下；AI 未配置时生成与 Agent 均禁用。
- **识别而非回忆**：图标 + 文字标签成对出现；筛选芯片可见可关；命令面板可搜索全部动词。
- **灵活高效**：确认三和弦、Ctrl+1..9 应用记忆、Ctrl+1..4 切坞、F3/F4、Alt+↑↓、命令面板；鼠标路径全部等价。
- **极简美学**：一套字体系统、一个 8px 间距尺度、一个强调色；无装饰性图形，个性来自密度、字重与状态工艺。
- **错误恢复**：QA 卡片给出"修复为 + 应用修复"；导出门提供"查看 QA 面板 / 仍要导出"；引擎闸门给出错误码与重启动作。
- **帮助**：快捷键全部记录在控件 tooltip 上。

## Fable Art 系列的边界

四份艺术稿与三份 SaaS 稿跑同一个引擎、同一份清单：文件树、双语网格、四坞、预览、八个对话框、命令面板、九个场景一个不少；实验性只落在材质、字体与动效层。全部动效尊重 `prefers-reduced-motion`，全部对比度按正文可读校准。

## 已否决的旧方向

`folio/`、`nocturne/`、`beton/`、`kinetic/` 四个艺术向方案已被否决（风格不实用、功能覆盖不全），仅保留存档。
